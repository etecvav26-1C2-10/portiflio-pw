### portiflio-pw

<h1>Bem-vindos ao portifolio-pw</h1>
<p>Este portfólio reúne atividades desenvolvidas na disciplina de Programação Web (PW), incluindo projetos em HTML, CSS, arquivos em Markdown (.md) e trabalhos realizados em grupo.

Ao longo dessas atividades, exploramops a criação de páginas web, estilização de interfaces e organização de conteúdos, sempre buscando deixar os projetos claros, funcionais e bem apresentados. Os arquivos em Markdown ajudaram na documentação e organização das ideias, enquanto os trabalhos em grupo contribuíram para o desenvolvimento da colaboração, comunicação e divisão de tarefas.

Este portfólio representa não só o que aprendemos na prática, mas também nossa evolução no desenvolvimento web e na capacidade de trabalhar em equipe</p>
